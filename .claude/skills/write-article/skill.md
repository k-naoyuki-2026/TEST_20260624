# write-article

記事を生成するスキルです。テーマやキーワードを受け取り、読みやすい日本語の記事を作成します。

## トリガー

ユーザーが以下のような要求をした場合に使用してください:
- 「記事を書いて」
- 「ブログ記事を作成して」
- 「〇〇についての記事」
- `/write-article`

## 手順

1. **テーマの確認**
   - ユーザーからテーマ・キーワード・対象読者・文字数の目安を確認する
   - 指定がない場合はデフォルト（一般向け、800〜1200字程度）で進める

2. **構成を決める**
   - タイトル
   - リード文（記事の概要、2〜3文）
   - 本文（見出しを2〜4つ設けて展開）
   - まとめ

3. **記事を執筆する**
   - 日本語で、わかりやすく読みやすい文体で書く
   - 専門用語は必要に応じて補足説明を加える
   - 見出しは `##` または `###` を使用する

4. **出力形式**
   - Markdown 形式で出力する
   - ファイルに保存する場合は `articles/` ディレクトリに `YYYYMMDD-<slug>.md` の形式で保存する

## 使用例

```
/write-article AIの未来について、初心者向けに1000字程度で書いて
```
